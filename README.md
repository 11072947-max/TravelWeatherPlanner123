# 🌍 Travel Weather Planner

### ✈️ Плануйте подорожі з комфортом за будь-якої погоди!

**Travel Weather Planner** — це зручний помічник для планування міських подорожей, який допоможе заздалегідь підготуватися до погодних умов та нічого не забути!

Програма отримує актуальний прогноз погоди, аналізує погодні показники та автоматично формує персональний чекліст необхідних речей для вашої подорожі. 🧳

---

## 🚀 Можливості

- 🏙️ **Планування подорожі** — введення бажаного міста та дати поїздки.
- 🌤️ **Прогноз погоди** — отримання погодних даних за допомогою OpenWeatherMap API.
- 🌡️ **Аналіз погодних умов** — перевірка температури, опадів і швидкості вітру.
- 🧥 **Персональні рекомендації** — автоматичне формування списку одягу та необхідних речей відповідно до прогнозу.
- 📲 **Інтеграція з Telegram** — можливість отримати прогноз погоди та готовий чекліст безпосередньо в Telegram через Telegram Bot API.

---

## 🛠️ Використані технології

Для реалізації проєкту використовуються:

- 🐍 **Python** — основна мова програмування.
- 🔗 **Requests** — виконання HTTP-запитів.
- 🔐 **python-dotenv** — безпечне завантаження конфігураційних змінних із файлу `.env`.
- ☁️ **OpenWeatherMap API** — джерело погодних даних.
- 🤖 **Telegram Bot API** — надсилання повідомлень користувачу.

---

## ⚙️ Встановлення та запуск

Щоб розпочати роботу з Travel Weather Planner, виконайте декілька простих кроків.

### 1. Встановіть Python 🐍

Переконайтеся, що на вашому комп'ютері встановлено Python.

### 2. Встановіть необхідні бібліотеки 📦

Відкрийте термінал у папці проєкту та виконайте команду:

```bash
py -m pip install -r requirements.txt
```

### 3. Налаштуйте API-ключі 🔑

Створіть у кореневій папці проєкту файл `.env` та додайте до нього свої ключі доступу:

```dotenv
OPENWEATHERMAP_API_KEY=your_openweathermap_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_telegram_chat_id
```

Замініть значення-заповнювачі на власні дані.

### 4. Запустіть програму ▶️

Після завершення налаштувань виконайте:

```bash
py main.py
```

🎉 **Готово!** Тепер можна планувати подорожі з урахуванням погодних умов!

---

## 🔒 Безпека

Для захисту особистих даних та API-ключів дотримуйтеся простих правил:

- Не публікуйте файл `.env` у відкритому доступі.
- Ніколи не передавайте свої API-ключі стороннім особам.
- Обов'язково додайте `.env` до файлу `.gitignore`, щоб конфіденційні дані випадково не потрапили до Git-репозиторію.
